# Silent Pines — Roadmap / список задач

Рабочий файл для себя. Не часть «мира» сайта — просто чтобы ничего не потерялось
и можно было вернуться на свежую голову.

---

## ⚠️ УРОКИ (дорого дались — не повторять)

1. **Мобильное проверять ТОЛЬКО на реальном телефоне.**
   Узкое окно браузера и эмуляция DevTools ВРУТ — заголовок влезал в узком окне,
   но на настоящем экране переносился и налезал на вывеску. Эмуляция hover тоже
   врёт (та же история была с tooltip). Проверять через Netlify или локальный
   Network-адрес (`npm run dev` печатает `Network: http://192.168.x.x:3000`),
   открыв с телефона в той же Wi-Fi.

2. **НЕ править один файл параллельно руками (Zed) и через Claude Code.**
   Отсюда весь хаос: «file changed on disk», потерянные правки, откаты,
   сломанная сборка. ОДИН источник правок за раз. Если Claude Code правил файл —
   перед ручной правкой закрыть и переоткрыть файл в Zed.

3. **Коммитить точки сохранения по ходу.** Свежий коммит = всегда есть куда
   откатиться.

4. **Вес изображений — критичен для мобильного и Instagram.**
   Генераторные картинки (Nano Banana и т.п.) бывают по 1–2 МБ каждая. На Wi-Fi
   незаметно, но Instagram in-app browser на LTE их не тянет — картинки не грузятся.
   Решение: жать в WebP (q82) — вес падает на ~90% без потери качества.
   НЕ нужны AVIF / srcset / 4 responsive-размера для маленького сайта — это
   переусложнение. Простой WebP решает проблему. Проверять именно в Instagram
   in-app browser на мобильном интернете.
