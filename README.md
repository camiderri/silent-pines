# Silent Pines — Tourism Website

Одностраничный сайт туристического городка **Silent Pines** — тихого места, окружённого лесом, туманом и историями. Атмосфера мрачного винтажного путеводителя.

## Стек

- **Next.js** (App Router)
- **Tailwind CSS**
- **lucide-react** — иконки

Иллюстрации сгенерированы с помощью ИИ .

## Секции

Header, Hero, About, Places, цитата с погодными индикаторами, Visitor Guide, интерактивная карта, Plan Your Stay, Footer.

## Как запустить локально

```bash
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000).
